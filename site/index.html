3. Apple Calendar subscription

Subscribe once to the public dividend calendar for events published by this GitHub project. Each event includes the percentage, sen per unit/share, numeric payout example where applicable, and source in its Notes.

View public .ics feed

Mac: Calendar → File → New Calendar Subscription → paste URL → choose iCloud → refresh daily. iPhone: Calendar → Calendars → Add Calendar → Add Subscription Calendar.

Privacy / limitation: Your private holdings and manually entered records are browser-only. Downloading “my personal .ics” imports a snapshot; it does not auto-update. The public subscription automatically refreshes only when the published GitHub feed changes. Personal holdings cannot be inserted into a private auto-updating feed from static GitHub Pages alone.
