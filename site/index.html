How automatic stock tracking works

The website is hosted on GitHub Pages. GitHub Actions retrieves dividend events for the stock codes being tracked and publishes fresh JSON and calendar files daily. The initial list includes several common Bursa stocks. If you add a new ticker not yet tracked, click Request tracking beside it. GitHub opens a prefilled issue; submitting that issue triggers a rebuild. You only need to supply the ticker, not dividend information.

Data limits: Stock amounts/ex-dates come from a third-party market-data feed, not official Bursa announcements. Provider failures or missing dividend events can result in incomplete records. Future announcement/payment dates are not guaranteed. Always check Bursa Malaysia or the company's investor-relations announcement before trading.
